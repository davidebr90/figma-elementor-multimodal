# Installation and first connection

## Before you start

You need WordPress 7.0+, PHP 8.3+, a valid and active Figma license, Figma Desktop, and a test page. Importing to Elementor requires Elementor 3.20+; Gutenberg does not require Elementor.

Use HTTPS for a real website. The wizard’s HTTP mode is reserved for `localhost`, `127.0.0.1`, and `[::1]` during local development.

## 1. Prepare WordPress

1. Download the WordPress archive from a release, or build a package from source as described in [DEVELOPMENT.md](DEVELOPMENT.md).
2. In WordPress, open **Plugins → Add New → Upload Plugin** and upload the ZIP.
3. Activate **Figma Elementor Multimodal**.
4. Confirm that the website does not show the PHP notice and, if Elementor will be used, the Elementor-version notice.
5. Open **Tools → FEM Pairing**.

Activation creates only WordPress-prefixed `fem_` tables; deactivation does not delete designs, snapshots, or audit history. Back up the database before the first test on an existing website.

## 2. Create the pairing

1. On the **FEM Pairing** page choose a Figma connection lifetime: **8 hours** or **7 days** for a trusted workstation.
2. Select **Generate pairing code**.
3. Use the page’s copy buttons for the **site URL**, **Pairing ID**, and **code**.
4. The code is single-use and expires after ten minutes. Generate a new one if it expires.

The code is not shown again after a refresh. The bearer issued after exchange stays only in Figma plugin private storage and can be renewed before it expires.

## 3. Prepare the Figma plugin

FEM Setup is the recommended route:

1. Open FEM Setup.
2. Enter the website origin, such as `https://example.com`, without `/wp-admin`, credentials, query, or fragment.
3. Select **Verify connection**. The check confirms that WordPress and the FEM namespace respond; it does not yet certify a Figma import.
4. Close FEM if it is open in Figma, confirm it in the wizard, and select **Prepare files**.
5. Copy the generated manifest path.

FEM Setup writes a local copy per site and puts only the selected domain in its manifest. Do not use the source manifest with permissive domains for a public website.

## 4. Import in Figma Desktop

1. In Figma Desktop open **Plugins → Development → Import plugin from manifest…**.
2. Select the manifest generated by FEM Setup.
3. Start **Figma Elementor Multimodal** from **Plugins → Development**.
4. Paste the URL, Pairing ID, and code; choose **Connect to WordPress**.
5. Select a frame or component. If present, associate desktop, tablet, and mobile variants before importing.
6. Choose the WordPress page and the target: Elementor or Gutenberg.
7. Start the import and wait for the asset, warning, and snapshot summary.

## 5. Verify the result

1. Open the test page in WordPress.
2. For Elementor, open the editor and inspect structure, text, images, margins, padding, borders, and responsive breakpoints.
3. For Gutenberg, check the **FEM Scene** block in both the editor and front end.
4. Test desktop, tablet, and mobile. Make WordPress-side corrections where needed, then publish only after a complete visual review.

For connection or import failures, consult [SECURITY.md](SECURITY.md), [LIMITATIONS.md](LIMITATIONS.md), and the WordPress server log without publishing credentials or temporary codes.
