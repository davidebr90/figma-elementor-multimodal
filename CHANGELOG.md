# Changelog

All notable changes are documented in this file.

## 0.1.0-beta — 2026-09-07

- First public beta of the Figma → WordPress flow.
- Elementor and Gutenberg output paths with FEM node/class traceability.
- Pairing screen with copy actions, selectable 8-hour or 7-day credential duration, and automatic renewal before expiry.
- Scoped, expiring pairing credentials; ownership checks; staged import persistence; content integrity validation; and commit idempotency.
- Site-scoped Figma manifest generation through the FEM Setup desktop wizard.
- Italian and English installation, security, limitations, and installer-status documentation.

## Compatibility promise

Until version 1.0, schemas, mappings, and installer behavior may change between minor releases. Test updates on a staging website first.
