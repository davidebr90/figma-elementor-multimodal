# Riferimenti tecnici pubblici

FEM si basa esclusivamente su API e contratti pubblicamente documentati o su formati WordPress standard. Prima di aggiornare le dipendenze, verificare sempre le note di compatibilità delle versioni interessate.

- [Figma Plugin API: richieste di rete](https://developers.figma.com/docs/plugins/making-network-requests/)
- [Figma Plugin API: manifest](https://developers.figma.com/docs/plugins/manifest/)
- [Elementor: registrare un widget](https://developers.elementor.com/docs/widgets/add-new-widget/)
- [Elementor: controlli widget](https://developers.elementor.com/docs/widgets/widget-controls/)
- [WordPress Block Editor handbook](https://developer.wordpress.org/block-editor/)
- [WordPress REST API handbook](https://developer.wordpress.org/rest-api/)

Il supporto Elementor in questa beta mira agli elementi classici e ai blocchi nativi WordPress. Eventuali API sperimentali o non documentate non sono prerequisiti del flusso di import.
