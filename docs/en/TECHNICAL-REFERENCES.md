# Public technical references

FEM uses only publicly documented APIs and standard WordPress formats. Check the compatibility notes for the relevant versions before updating dependencies.

- [Figma Plugin API: making network requests](https://developers.figma.com/docs/plugins/making-network-requests/)
- [Figma Plugin API: manifest](https://developers.figma.com/docs/plugins/manifest/)
- [Elementor: add a widget](https://developers.elementor.com/docs/widgets/add-new-widget/)
- [Elementor: widget controls](https://developers.elementor.com/docs/widgets/widget-controls/)
- [WordPress Block Editor handbook](https://developer.wordpress.org/block-editor/)
- [WordPress REST API handbook](https://developer.wordpress.org/rest-api/)

The Elementor support in this beta targets classic elements and native WordPress blocks. Experimental or undocumented APIs are not import-flow prerequisites.
