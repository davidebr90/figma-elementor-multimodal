# FEM visual system

The approved FEM logo and visual assets are stored in [`assets/brand`](../../assets/brand/). The complete Italian brand guide is available in [`docs/brand/fem-visual-system.md`](../brand/fem-visual-system.md).

## Meaning

The symbol represents the same content across three connected levels: design/interface, editable block or page builder, and code/data structure. The arrows express the product’s direction of transformation while leaving room for a future reverse path.

## Tokens

| Token | Value | Intended use |
| --- | --- | --- |
| `--fem-orange` | `#FF5A3D` | visual design input |
| `--fem-magenta` | `#D50072` | Elementor and components |
| `--fem-blue` | `#2F6BFF` | import and connection |
| `--fem-navy` | `#172B44` | code and reliability |
| `--fem-gray` | `#6B7688` | secondary information |
| `--fem-white` | `#FFFFFF` | separators and contrast |

Use the primary logo in FEM administration, pairing screens, and documentation. Do not imply an affiliation with Figma or Elementor, and do not replace the white curved separators in the symbol.
