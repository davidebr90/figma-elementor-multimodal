# FEM Figma plugin

This package contains the Figma development plugin for Figma Elementor Multimodal.

For a real website, use the manifest generated by **FEM Setup**: it limits network access to the selected domain and pre-fills the URL. The source manifest is for local development only and must not be reused for production.

1. In WordPress, open **Tools → FEM Pairing** and generate temporary values.
2. Prepare the package in the `apps/installer` wizard.
3. In Figma Desktop choose **Plugins → Development → Import plugin from manifest…**.
4. Start FEM, enter the URL, Pairing ID, and code, then import a selection.

Detailed guides: [Figma](../../docs/en/FIGMA.md) · [Installation](../../docs/en/INSTALLATION.md) · [Limitations](../../docs/en/LIMITATIONS.md).
